Color Remember

Instrucciones

Este minijuego consiste en memorizar y seguir el orden correcto de las baldosas de color. Tienes un tiempo límite y tres vidas por si te equivocas, pero si el tiempo acaba o fallas mas de tres veces, perderás. En cambio, si consigues seguir la secuencia correcta antes de tiempo y sin usar mas de tres intentos, ganarás. Tendrás un indicador visual para seguir el orden y también un sonido que se reproduce con cada baldosa para que te ayude a memorizar el orden.
