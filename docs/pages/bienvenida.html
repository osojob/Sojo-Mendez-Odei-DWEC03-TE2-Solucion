Color Remember

Instrucciones

Este minijuego consiste en memorizar y seguir el orden correcto de las baldosas de color. En cada ronda se mostrará una secuencia de baldosas que se iluminan y suenan en orden. El objetivo es repetirla pulsado las baldosas en el mismo orden. Tienes un tiempo límite (30s fácil, 25s intermedio y 20s avanzado) y 3 vidas. Cada fallo te resta una vida, si pierdes las 3 vidas (4 fallos) o se acaba el tiempo, perderás. Si completas todas las rondas antes de que se acabe el tiempo y sin perder todas las vidas, ganarás una medalla. Tendrás un indicador visual (las baldosas se iluminan) y un sonido por cada baldosa para ayudarte a memorizar el orden.
